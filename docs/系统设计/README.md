# 系统方案设计文档库

本目录用于集中管理各类**系统方案设计（System Design）**文档，便于按主题归档、检索与迭代。

## 目录约定

- 每个系统/主题占用一个独立子目录，目录名即方案主题。
- 每个子目录内至少包含一份 `*.方案设计.md` 主文档；可附带子文档（如难点深挖、容量评估、压测报告等）。
- 文档统一使用 Markdown，架构图优先用 Mermaid（多数 Markdown 阅读器可渲染），关键性能数据用表格呈现。

## 新增方案步骤

1. 在本目录新建 `主题名/` 子目录。
2. 在子目录中撰写 `主题名.方案设计.md`，按"需求 → 架构 → 核心设计 → 关键技术难点"的结构组织。
3. 回到本 README 的「方案清单」追加一行索引。
