# 接口文档（FinPay）

基础地址：`http://localhost:8080`（直连业务）或经网关 `http://localhost:8088`。
除登录与回调外，所有接口需在 Header 携带 `Authorization: Bearer <token>`。

统一响应：`{ "code": 200, "message": "success", "data": ... }`，非 200 表示失败。

## 认证
### POST /auth/login
请求：`{ "username": "admin", "password": "admin123" }`
返回：`{ "data": { "token": "...", "username": "admin" } }`

## 支付网关（示例）
### POST /api/pay/create
入参（PayOrderRequest）：
```json
{ "channel":"alipay","merchantNo":"MOCK","amount":0.01,"subject":"商品",
  "currency":"CNY","tradeType":"NATIVE","notifyUrl":"http://.../callback/alipay/MOCK" }
```
返回：`{ "data": { "qrCode": "..." } }` 或 `{ "data": { "redirectUrl": "..." } }`

### POST /api/pay/refund
入参：`{ "outTradeNo":"P...","tradeNo":"","channel":"alipay","merchantNo":"MOCK",
"outRefundNo":"R...","refundAmount":0.01,"totalAmount":0.01,"reason":"测试" }`

### GET /api/pay/query?channel=&merchantNo=&outTradeNo=
### GET /api/pay/orders?channel=&status=&limit=

### POST /callback/{channel}/{merchantNo}
渠道异步回调入口（免鉴权）。内部完成验签 → 幂等更新订单。返回 `success` / `fail`。

## 状态码（ErrorCode）
| code | 含义 |
|---|---|
| 200 | 成功 |
| 10001 | 参数校验失败 |
| 10002 | 签名验签失败 |
| 10003 | 重复请求（幂等） |
| 20001 | 不支持的渠道 |
| 20002 | 渠道下单失败 |
| 30001 | 账户不存在 |
| 30002 | 余额不足 |
| 40001 | 无权限 |
| 40002 | 未认证 |
| 50001 | 对账不平 |
| 50000 | 系统异常 |

> 完整字段与示例可启动后访问 `http://localhost:8080/doc.html`（Knife4j）在线查看。
